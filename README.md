# 今日、学校休みかな

GitHub Pages 用の、軽量な文庫アプリ風Webアプリです。

## 公開前にすること

`index.html` 内の `STORY_PAGES` を完成原稿に差し替えます。本文を受け取ったら、こちらで作業します。

## GitHub Pages での公開

リポジトリの一番上（root）に、以下の5ファイルを置きます。

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `cover.png`

GitHubの **Settings → Pages** で、**Build and deployment** の Source を **Deploy from a branch**、Branch を **main / (root)** にして **Save**。
